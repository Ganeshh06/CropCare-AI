## 📌 About

**CropCareAI** is an AI-driven agriculture platform that uses Machine Learning and Deep Learning to provide useful farming recommendations.

The project provides three major systems:

* 🌾 **Crop Recommendation**
* 🧪 **Fertilizer Recommendation**
* 🍃 **Plant Disease Detection**

The goal is to make AI-based agricultural assistance accessible through a simple web application.

---

## ✨ Features

### 🌾 Crop Recommendation

Recommends suitable crops based on:

* Nitrogen, Phosphorus & Potassium
* Temperature
* Humidity
* Soil pH
* Rainfall
* Location

### 🧪 Fertilizer Recommendation

Analyzes soil nutrients and the selected crop to identify nutrient deficiencies/excesses and provide fertilizer suggestions.

### 🍃 Plant Disease Detection

Users can upload a plant leaf image to detect:

* Plant/Crop type
* Disease or healthy condition
* Possible disease
* Basic disease information
* Prevention suggestions

## ⚙️ Run Locally

### 1. Clone Repository

```bash
git clone <https://github.com/Ganeshh06/CropCare-AI.git>
cd CropCareAI
```

### 2. Create Environment

```bash
conda create -n CropcareAI python=3.6.12
conda activate CropcareAI
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Application

```bash
cd app
python app.py
```

Open:

```text
http://127.0.0.1:5000/
```
